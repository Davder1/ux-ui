# 2. házi feladat – Affinity map és journey map

## Projekt

FoodLens – élelmiszer-értékelő alkalmazás koncepciója.

## Feladat célja

A szimulált kutatási jegyzetek rendszerezése, a visszatérő mintázatok
azonosítása, valamint insightok, persona és user journey elkészítése.

## Elkészült feladatok

- Kutatási jegyzetek létrehozása AI segítségével.
- Idézetek, megfigyelések és értelmezések elkülönítése.
- Affinity map elkészítése.
- Két insight megfogalmazása.
