# FoodLens

A FoodLens egy élelmiszer-értékelő alkalmazás koncepciója, amely segít a vásárlóknak megérteni az élelmiszerek összetevőit és tápértékadatait. A projekt célja, hogy a felhasználók egyszerűbben dönthessenek arról, mennyire jó választás egy adott termék. Jelenleg az ötlet és a probléma feltárásának szakaszában tart.
